# Better-Steam-Extension
这是对[Extendium](https://github.com/BossSloth/Extendium)的优化版本                                                                                                         
**Steam**本质上是一个chrome套壳的浏览器，你可以通过一些操作给它安装浏览器扩展，但操作较为复杂不方便管理，[Extendium](https://github.com/BossSloth/Extendium)正是为解决这一问题而来  
>Extendium是一个Millennium插件，能够管理steam安装的扩展，包括卸载、安装、扩展设置                                                                                              
>而[Millennium](https://steambrew.app/)是一个可以安装到steam客户端的插件，有了它就可以给steam安装主题和插件
## 本项目对[Extendium](https://github.com/BossSloth/Extendium)的优化
对英文文本汉化，点击扩展按钮所展示的扩展预览窗口增加**滚动**功能，不再是生效的扩展越多，该预览窗口越长，甚至长到屏幕外，管理扩展按钮根本点不到，管理扩展按钮固定在预览窗口底部，不随滚动显示和隐藏                                                                                                                                                                       
## 安装
安装Millennium                                                                                                                                                             
下载本项目并解压                                                                                                                                                            
找到(steam安装的盘符)\steam\millennium\plugins,把解压的文件放进去                                                                                                            
在Millennium的插件设置中启用Extendium，根据提示重启steam确保插件生效
